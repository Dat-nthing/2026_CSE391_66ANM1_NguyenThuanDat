## ✨ Giới thiệu

Repo này là “**nhật ký luyện tập**” cho hành trình học **Frontend Web Fundamentals**.  
Mình sẽ cập nhật đều đặn theo từng buổi, ưu tiên:

✅ Code rõ ràng — ✅ Semantic HTML — ✅ Tối ưu trình bày — ✅ Thực hành thật

> Nếu bạn đang học cùng môn, có thể dùng repo này như một “bản đồ ôn tập”.

---

## 🎯 Mục tiêu
- Lưu trữ bài thực hành & bài tập theo buổi
- Tổng hợp kiến thức HTML/CSS/JS theo dạng “dễ tra”
- Làm nền cho mini-project cuối kỳ

---

## 🧰 Công nghệ sử dụng

- **HTML5**: cấu trúc trang, semantic, table, form  
- **CSS3**: layout, responsive, typography, animation cơ bản  
- **JavaScript (ES6+)**: DOM, events, logic cơ bản  
- **Git & GitHub**: quản lý phiên bản, lưu trữ bài tập, teamwork flow  

---

## 🚀 Cách chạy project

- Mở file `.html` bằng trình duyệt  
hoặc
- Dùng VS Code extension **Live Server** → Right click `index.html` → **Open with Live Server**
